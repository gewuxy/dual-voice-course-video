# 正面经验（做对了的做法）

> 和 `known_pitfalls.md` 互补：那边记**踩过的坑**（会被修掉），这边记**做对的做法**（不然会被忘掉）。
> 每支课做完往这里加。条目格式：**做法 + 证据 + 为什么 + 何时用**——四条缺一不可，没有证据的直觉不写进来。

## 条目模板

```
### <一句话做法>
- **做法**：具体怎么做的（可复制的命令 / 参数 / 结构）
- **证据**：哪支课、哪个指标、对比结果（量化的最好）
- **为什么**：它解决了什么问题，机制是什么
- **何时用**：什么条件下套用；什么条件下不要用
```

## 已沉淀

### 成片合成只走硬链接帧序列

- **做法**：`make_video.sh` 内部按 `durations.txt` 把每张 shot 硬链接 `round(dur×30)` 次，再严格 CFR 30fps 编码，音轨第二步 `-c:v copy` 混流
- **证据**：三种替代路径全部实测失步——`-framerate` 直读 shots 把每区间当 1/30s；concat demuxer 输出 VFR，t=50 处错位一个区间；concat 上加 `-r 30`/`fps` 滤镜漂移更大（415s vs 398s）
- **为什么**：截图是"每视觉变化区间一张"，不是均匀帧率；只有把区间时长还原成重复帧，时间戳才与音频对齐
- **何时用**：所有静帧版成片。**例外**：`capture_anim.js` 产物本身均匀 30fps，直接 `-framerate 30` 编码即可，走硬链接反而多余

### step 按 class 分词识别，允许叠动效 class

- **做法**：`make_standalone.py` / `verify_steps.py` 用 `(?<![-\w])step(?![-\w])` 匹配 class 列表，`<div class="step anim-pop">` 一样认
- **证据**：修复前同一份 3 帧 × 2 step（4 个带动效 class）用例只数到 2 步（应为 6）且无报错；修复后 6 步，且 step 数与台词句数不符时显式提示
- **为什么**：漏掉的 step 拿不到 `.on`，CSS 是 `opacity:0` → 画面内容在成片里永久不可见，且不报错
- **何时用**：写放映版时 `.step` 上可直接叠 `anim-pop` / `anim-slam` / `anim-fade-rise` 等 class；改匹配逻辑时两侧脚本必须同口径

### 封面双模板固定制，每课固定出两张（2026-10-14 回填 L8 实证比例）

- **做法**：横版取 `封面模板_横版课件_1920x1080.html`，竖版取 `封面模板_竖版视频号_1080x1260.html`，改 4 个【替换】点（徽章 / 主标题 / 副标题 / 钩子句或对比句 + 贴纸卡）；主标题字号按词数给（2 字 206 / 3 字 176 / 4 字 150），贴纸卡 `width:300px` 自适应高，**插画必须按本课主题重画**
- **证据**：2026-10-02 用户定稿；2026-10-14 L9 复现问题——照旧模板做只有**内容占画布 78.2%**，同课按 L8 比例重平衡后 **93.1%**（L8 实测 93.1%；贴纸卡 326×337 vs 旧模板 271×294）；品牌行 y≈1112 在 1:1 安全区 y=90~1170 内；徽章 y≈60 会被 1:1 裁切切掉顶边（已确认接受，见 `stages/5-cover.md`）
- **为什么**：模板只留文字替换点、把内容尺寸写死时，标题长度一变构图就失衡；而"做得好的那一课"如果不回填模板，下一课必然退回旧观感
- **何时用**：所有课。**例外**：用户明确要求新版式时，改完必须把新模板回填进 `assets/style-packs/crayon/`，并重新验证安全区与内容占画布（横版目标 90% 以上）

### 动效按"角色"分布，不按"课型"一刀切（2026-10-14 L9 实测）

- **做法**：先落「动效清单表」（帧×步×课型×角色×动效，见 `stages/2-slides.md`），再按 `anim-snippets/README.md` §二 候选池挑；组件的动效参数**不给会被一路复制的默认值**；**禁止一刀切兜底动效**（兜底只给装饰层）。
- **证据**：L9 第一版 9 个 visual 帧里 `anim-fade-rise` 占 7/12（58%），观感"每个画面都在往上飘"；按角色重分配后 **9 帧 / 9 种动效、单帧 2–6 种、最大占比 17%**（`fly-left×6`、`fly-right×6`、`pop×6`、`fade-rise×6`、`slam×4`、`iris-in×3`、`blur-in×2`、`rise×1`）。反例自测：把新版动效全换回 `fade-rise`，`qc_variety.py` 立刻报"visual 帧内 fade-rise 占 7/12（>50%）"。
- **为什么**：单一化的三个真凶是——① 组件默认值（一次设定、处处复制）；② 兜底规则（漏标也照动，把问题藏起来）；③ 文档里"同课型同一套动效完全正确"这句豁免。三条都在代码/文档层，不在审美层。
- **何时用**：所有课。同课型帧占多数时（流程/步骤类）尤其必须走角色分，否则必然趋同。

### 音效落位：silencedetect 细切 + 自适应合并到台词行数（2026-10-14 L9 实证）

- **做法**：帧起点查 `report.json` 的帧级 `dur`（Σ前帧 dur + `frame_gap`），帧内用 `silencedetect` 细切，再按间隙阈值（0.5–1.3s 阶梯）**自适应合并到该帧台词行数**；表情行跳过；台词前缀校验不符即 `exit 1`。**必须对最终采用的变速版本音频跑**（变速后静音窗口会整体位移）。
- **证据**：L9 六帧实测细切出 9–14 段，合并后全部对齐 4 行；`report.json` 的 `units` 时刻偏差可达 6s+，只能粗对齐（见 `known_pitfalls.md` §6）。
- **为什么**：TTS 句内自然停顿会被切成很多段，直接按段数落音效必然错位；按"台词行数"合并才有语义。
- **何时用**：所有需要精确落位的音效/字幕时刻。

### GSAP 轨接入：让时间轴动效也能进片（2026-10-15 实测定案）

- **做法**：时间轴用 `MO.timeline()` 建（内部 `MO.register` 登记，浏览器里照常自动播放）；页面时间轴代码写在 `<script id="mo-timeline">` 里；`make_standalone.py` 自动内联内置 gsap（`assets/vendor/`，离线）+ `mo.gsap.js` + 那段脚本，并在生成的 `applyTime(t)` 末尾调 `MO.seek(t)`（`gsap.ticker.sleep()` + 逐个 `tl.pause(); tl.time(t, false)`）。
- **证据**：验证页 t=2.0→3.2 的红点做 `x:-360,y:-200,rotation:360` 曲线位移，抓帧实测质心 **457,327 → 435,314 → 277,227 → 97,127**（逐帧推进，终点符合预期）；GSAP 入场（`MO.entrance` pop @1.0s）在 t=0.5 不可见、t=1.25 已出现。另：`applyTime(2.6)` 后元素 transform = `translate(-180,-100) rotate(180°)`，正好是区间的**一半**——确定性 seek 可复核。
- **为什么**：`capture_anim` 只认 `document.getAnimations()`，GSAP 默认用自己的 rAF ticker 改 inline style，不进 WAAPI；显式 seek 才是正解。接入后 GSAP 的能力（形变 MorphSVG / 描线 DrawSVG / 路径 MotionPath / 逐字 SplitText）成为**白板、手绘、3b1b 类风格**的底座。
- **许可**：GSAP 3.15.0「Standard No Charge」许可，**商用免费**（含原会员插件）；内置件保留版权 banner，许可与结论见 `assets/vendor/gsap.LICENSE.txt`。
- **何时用**：CSS 表达不了的动效（曲线路径、形变、逐字、时间轴倒放/倍速）走 GSAP；普通入场/微动仍优先 `mo.css`（更轻、更好维护）。**同一元素别同时挂 CSS class 和 GSAP tween。**
