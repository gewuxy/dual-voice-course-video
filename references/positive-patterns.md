# 正面经验（做对了的做法）

> 和 `known_pitfalls.md` 互补：那边记**踩过的坑**（会被修掉），这边记**做对的做法**（不然会被忘掉）。
> 每支课做完往这里加。条目格式：**做法 + 证据 + 为什么 + 何时用**——四条缺一不可，没有证据的直觉不写进来。

## 条目模板

```
### <一句话做法>
- **做法**：具体怎么做的（可复制的命令 / 参数 / 结构）
- **证据**：哪支课、哪个指标、对比结果（量化的最好）
- **为什么**：它解决了什么问题，机制是什么
- **何时用**：什么条件下套用；什么条件下不要用
```

## 已沉淀

### 成片合成只走硬链接帧序列

- **做法**：`make_video.sh` 内部按 `durations.txt` 把每张 shot 硬链接 `round(dur×30)` 次，再严格 CFR 30fps 编码，音轨第二步 `-c:v copy` 混流
- **证据**：三种替代路径全部实测失步——`-framerate` 直读 shots 把每区间当 1/30s；concat demuxer 输出 VFR，t=50 处错位一个区间；concat 上加 `-r 30`/`fps` 滤镜漂移更大（415s vs 398s）
- **为什么**：截图是"每视觉变化区间一张"，不是均匀帧率；只有把区间时长还原成重复帧，时间戳才与音频对齐
- **何时用**：所有静帧版成片。**例外**：`capture_anim.js` 产物本身均匀 30fps，直接 `-framerate 30` 编码即可，走硬链接反而多余

### step 按 class 分词识别，允许叠动效 class

- **做法**：`make_standalone.py` / `verify_steps.py` 用 `(?<![-\w])step(?![-\w])` 匹配 class 列表，`<div class="step anim-pop">` 一样认
- **证据**：修复前同一份 3 帧 × 2 step（4 个带动效 class）用例只数到 2 步（应为 6）且无报错；修复后 6 步，且 step 数与台词句数不符时显式提示
- **为什么**：漏掉的 step 拿不到 `.on`，CSS 是 `opacity:0` → 画面内容在成片里永久不可见，且不报错
- **何时用**：写放映版时 `.step` 上可直接叠 `anim-pop` / `anim-slam` / `anim-fade-rise` 等 class；改匹配逻辑时两侧脚本必须同口径

### 封面双模板固定制，每课固定出两张

- **做法**：横版取 `preview.html` 第 1 页「封面」slide，竖版取 `封面模板_竖版视频号_1080x1260.html`，只改 3 个【替换】点
- **证据**：2026-10-02 用户定稿；品牌行 bottom:118px（y≈1112）已验证落在 1:1 安全区 y=90~1170 内
- **为什么**：每课另选版式会导致系列视觉不一致、且每次都要重新验证安全区
- **何时用**：所有课。**例外**：用户明确要求新版式时，改完必须把新模板回填进 `assets/templates/crayon/` 并重新验证安全区
