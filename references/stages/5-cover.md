# 阶段 5 · 配套封面（命令与模板）

双模板固定制、风格铁律、1:1 安全区原则、确认 gate：见 `SKILL.md` 阶段 5（本文件只放命令与路径）。

## 模板（勿改结构）

| 模板 | 画布 | 文件 |
| --- | --- | --- |
| 横版课件封面 | 1920×1080 | `$SK/assets/style-packs/crayon/封面模板_横版课件_1920x1080.html` |
| 竖版视频号封面 | 1080×1260 | `$SK/assets/style-packs/crayon/封面模板_竖版视频号_1080x1260.html` |

**模板规则（2026-10-14 按 L8 成品比例回填）**：

| 部位 | 规则 |
| --- | --- |
| ① 徽章 | 课号 + 年级（位置固定不改） |
| ② 主标题 | **字号按词数给**：2 字 206 / 3 字 176 / 4 字 150；两个词用 0.6 倍字号的连接字（「与」「·」）分隔；横版用 `.hl` 荧光笔，竖版用两个 `mark.y/g` |
| ③ 副标题 | ≤14 字、目标宽 **900–1050px**（横版 72px），下面带手绘波浪线 |
| ④ 钩子句 | 娃娃体 58px、≤16 字，压在主标题上方——**封面最抓人的一句**；不写就删掉这一行 |
| ④ 竖版 | 副标题改成**对比句**（A vs B，vs 用 #C2255C）；左右贴纸卡 330×440 + 中圆 + 手写批注 |
| 贴纸卡 | 横版 `width:300px` + 内边距**自适应高**（别写死高度），卡下说明 32px；**插画必须按本课主题重画**（模板里的样例是 L8 的，照抄就是"一课一样"） |
| 品牌行 | 固定不改 |

**尺寸自检（新增）**：渲染后用 puppeteer 量「所有可见元素外接框 / 画布」——**横版应 ≥90%、竖版 ≥85%**；低于 85% 说明标题偏小或卡片偏挤，回去调 ②③④。

⛔ **凡做了"新版式"级改动（换字号体系 / 换卡片尺寸 / 加新元素），必须把改动回填进这两个模板文件。**

## 工作流与命令

**1:1 安全区**：品牌行在安全区内；徽章顶边会被裁切切到（成因见 `known_pitfalls.md` §10），默认**接受**。某课不接受就把该课 HTML 的 `.badge` 下移 ~30px 并在交付说明注明，**不要改模板**。
**先出 HTML 风格稿（用模板填内容）→ 用户确认 → 再 puppeteer 截图出图**。截图参数：1080×1260 viewport + `document.fonts.ready` + 300ms 等待；用 `qc_frames.js` 同源的 puppeteer 能力（Chrome + 自动找 puppeteer-core）。

1:1 裁切自查（视频号信息流按 1:1 居中裁切，取 y=90~1170）：

```bash
ffmpeg -y -i "$H/视频课/封面/封面_竖版_*.png" -vf crop=1080:1080:0:90 -q:v 3 "$H/视频课/封面/自查_1比1裁切_竖版.png"
```

## 产出

- `$H/视频课/封面/封面_横版_*.png`（1920×1080）
- `$H/视频课/封面/封面_竖版_*.png`（1080×1260）
- `$H/视频课/封面/自查_1比1裁切_*.png`

取向 = both 时横竖都出。出图后用户要调就改 HTML 重截，不反复猜。
