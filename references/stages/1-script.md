# 阶段 1 · 写演讲稿（命令与格式）

产出 `$H/视频课/script_v2_dialog.txt`——驱动 HTML 帧结构与 TTS 的**唯一真相源**。
认知铁律、视频介质改写、角色分配原则：见 `SKILL.md` 阶段 1（本文件不重复）。

## 格式（被 `verify_steps.py` 解析）

```
【第 1 帧】开场 · 主题
老师："请你仔细观察，它是什么颜色的？"[[1.2]]
学生："红色！"[[0.8]]
```

- 帧头 `【第 N 帧】`（`N` 前后允许空格）
- 角色行：老师固定 `老师：`，学生 `学生：`，台词用中文引号包裹
- `[[n]]` = 该句**之后**的静音秒数（学生思考 / 做动作的时间）
- 学生行含「哭脸 / 笑脸」→ 不念词，只留静音（做表情）
- 引号内不要出现 `"` `"`，否则解析器会漏句
- **一帧内的角色行数 = 该帧 HTML 的 `.step` 数**（阶段 4 能 1:1 对齐的唯一依据）

## 校验（阶段 1、2 各做完都跑一次）

```bash
python3 $SK/scripts/verify_steps.py "$H"
```

打印每帧 `.step` 数 vs 该帧台词句数，不一致即报错并 `exit 1`。step 数缺失会静默退化为帧内均匀分布（画面提前泄题），所以这一步不能跳。

## 关键词表（阶段 1 gate 时与剧本一并确认）

字幕里黄底橙字高亮的词。权威来源 = `$H/视频课/course_config.json` 的 `subtitle_keywords`，阶段 4 `make_standalone.py` 自动读取，**横竖版共用一份**——杜绝两次生成各编一套。

提炼规则：
- **本课核心概念词**：老师嘴里反复说的专业名词（如 L8 = 分类/搜索/特征/线索/决策树），从**剧本台词**里挑，不从教案目录挑
- 每课 **5 个左右**（L1 传感器家族 9 个是特例，别超 10）
- 学生日常词不进表；「积木分家家」这类口头语若当时误入过，重做时可删
- 写入：
```json
"subtitle_keywords": ["分类", "搜索", "特征", "线索", "决策树"]
```

**为什么必须在阶段 1 确认**：词表没有权威来源时会**静默缺失**（`kw_source=none` 不报警、字幕就是没高亮）。L8 的实际事故：CLI 临场忘传 + config 无字段双缺失 → 竖版字幕无高亮 → 全量重截 11253 帧返工。已出各课（L1–L8）的词表已按历史成片实际高亮词补进 config。
