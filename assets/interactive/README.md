# 交互层（interactive）· 规划中

**目标**：把"点一下出下一句"的放映式课件，升级成**学生能动手、立刻知道对错**的 H5。
视频不再是平行产物——它是这份 H5 在 `mode=record`（按脚本化答案自动走）下的录屏。

## 一、契约（先定下来，实现按此写）

| 项 | 约定 |
|---|---|
| 结构 | 交互元素必须能在**时间驱动模式**下被确定性复现（与 `applyTime(t)` 同源） |
| 状态 | 只切**状态类**：`--idle / --sel / --drag / --ok / --err / --done`；样式由风格包给 |
| 判定 | 组件自己判定（数据里声明答案），反馈 ≤0.6s 可见 |
| 奖励 | 星星/进度由**页面级**统一管理（组件只回报结果），不各写一套 |
| 错误 | **不扣分、不打断**：提示 + 允许原地重试 |
| 触摸 | 热区 ≥88×88px；拖拽用 Pointer Events（触摸/鼠标同一套） |
| 中性 | 组件不得写颜色/字体/圆角——全部走风格包 tokens |

## 二、计划组件（按 L9 实际需要排优先级）

| 组件 | 用途 | 状态类 | 进片（record 模式）行为 |
|---|---|---|---|
| `sort-cards` | 拖卡排序（算法顺序） | `--sel/--drag/--ok/--err` | 自动播放"错误→纠正"或"一次对" |
| `tap-choose` | 点选（二选一/多选） | `--sel/--ok/--err` | 自动高亮正确项 |
| `drag-match` | 拖拽配对（形状↔名字） | `--drag/--ok/--err` | 连线动画替代拖拽 |
| `flip-card` | 翻牌记忆 | `--done` | 依次翻开 |
| `connect-line` | 连线（顺序/归属） | `--ok/--err` | 线条生长（`anim-write`） |
| `draw-pad` | 画一画（笑脸/路线） | `--done` | 描线回放（`anim-write` 或 DrawSVG） |
| `vote-bar` | 举手投票（统计条） | `--done` | 条形增长 |
| `progress-stars` | 关卡进度与集星 | `--on` | 随步骤增加 |

## 三、实现前置（已在管线里备好）

- ✅ 确定性时间轴：`make_standalone.py` 生成的 `applyTime(t)`（record 模式的基础）
- ✅ GSAP 轨 seek 注入：曲线路径 / 形变 / 描线（`DrawSVG` / `MorphSVG` / `MotionPath` 已离线内置）
- ✅ 动效库 26 条（CSS，进片可用）
- ✅ 风格包契约（组件只切状态类，皮肤由 pack 提供）
- ⬜ 交互组件本身（本目录）
- ⬜ 脚本格式扩展：每步可声明 `[互动: <组件> <参数>]` + `答案:`，视频侧读作"留白 + 揭晓"
