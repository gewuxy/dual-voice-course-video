# assets/intro —— 蜡笔风动态片头（2026-10-08 分屏改版）

## 这是什么

课程视频的**统一片头**：7.5 秒、蜡笔手绘风（与互动课件 `index_present.html` 同一套视觉令牌）。
**分屏节奏对齐 SkillStruck 参考片（L2 sensingandunderstanding.mp4 前 5 秒）**——每屏只有一个信息组，拍与拍之间留空白呼吸拍；课名**单独一屏**（2026-10-08 用户定案：不要把内容挤在一个画面里）。

| 文件 | 作用 |
|---|---|
| `intro_crayon_template.html` | 动画本体（自带 `applyTime(t)`，逐帧确定性；令牌化，支持任意时长等比缩放） |
| `logo.svg` | 官网 `https://xiaoxianai.cc/assets/logo.svg` 原件（黄底靛蓝四角星） |
| `../scripts/make_intro.sh` | 一键生成（替换令牌 → 渲染帧 → 配乐 → 编码） |
| `../scripts/make_intro_music.py` | 参数化配乐（100BPM / C 大调 I–V/V–vi–IV 琶音 + 铺底 + 沙锤 + 混响） |

## 配乐收声（2026-10-09 用户定案）

片头结尾前最后 **2.0 秒**用 `afade` 把配乐渐隐至静音，与画面蜡笔擦除同步收声，接正片第一帧时无音乐尾音。

- 调参：`--fade <秒>`（默认 2.0，`0` = 不淡出）/ `--curve <name>`（默认 `qsin` 四分之一正弦，比线性柔和）
- 实测（7.5s 片头）：7.20s −37dB → 7.40s −61dB → 7.45s 静音 → 7.50s 正片人声接入
- QC 注意：抽样窗口别跨段边界（0.3s 窗口在 7.45s 会把正片开头一起测进 RMS）

## 一键用法

```bash
SK=<本 skill 目录，你 clone 到的路径>     # 例：~/skills/dual-voice-course-video；或 cd 进 skill 目录用 $PWD
bash $SK/scripts/make_intro.sh \
  --out "$H/视频课/L3_片头_6.5s.mp4" \
  --title "第 3 课 · <em>事物的特征</em>"
```

默认文案就是 L3 已定稿那套（品牌名 / 主张句 / 配套三件套 / 不插电即可开课），换课只需改 `--title`。

## 分屏时间轴（基准 7.5s，其它时长按比例缩放；2026-10-08 用户定案：拍2 收短、拍3 拉长）

| 时刻 | 画面 | 备注 |
|---|---|---|
| 0.05–0.75s | 拍1：logo 单独居中飞入 | 独占 ≈0.8s（0.85 即开始左移） |
| 0.85–1.30s | 拍2：logo 左移滑入锁定位 | |
| 1.10–1.85s | 拍2：品牌名滑入 | 与 logo 入位交叠 |
| 2.30–2.65s | **呼吸拍：锁定组合淡出**（拍2 完整驻留 ≈1.0s） | 纯底 |
| 2.90–4.80s | 拍3：主张句 + 三件套逐个飞入 + 收尾句 | 整组同屏驻留至 6.00s（≈1.2s）；块间距 ≥90px |
| 6.00–6.30s | **呼吸拍：拍3 淡出** | 纯底 |
| 6.40–6.95s | 拍4：课名贴纸独屏 Q 弹落位 | 唯一主角，字号 86px；`<em>` 自动黄色高亮胶囊 |
| 7.15–7.45s | 蜡笔圆点擦除 | **末帧 = 纯奶油底，无缝接正片第 1 帧** |

## 已定案的设计约束（改之前先读）

1. **分屏铁律：每个画面只留一个信息组，课名必须独屏**（2026-10-08 用户定案「内容太拥挤」；对齐 SkillStruck 参考片节奏，拍间留纯底呼吸拍）。
2. **配乐不要卡点铃铛**（用户 2026-10-08 明确：听感像"音乐之外多了一层叮叮声"）→ `make_intro_music.py` 默认不加，`--bells` 才加。
3. **音轨数必须是 1**。`make_intro.sh` 结束会打印音轨数；=2 说明配乐和 `--music` 复用件叠加了。
4. **关键词高亮必须用 `inline-block`**，否则 `em` 的底色框会因断行机会偏离文字（踩过两次，见 known_pitfalls #21）。
5. **装饰元素（星星/波浪/圆点）不能压住文字**。飞入动画期间元素会位移，摆位时按"最终静止位置"留出至少一个卡片宽的余量。
6. **时长按比例缩放**：模板里所有时间点都过 `K(x) = x * TOTAL / 6.5`，改 `--total` 不需要动 JS。
7. 片头**不带念稿**（用户 2026-10-08 定案：片头只做品牌与价值主张，不念课程内容）。
8. 编码统一 `-ar 48000 -ac 2`（三段拼接规范，见 references/known_pitfalls.md §6 的采样率坑）。
