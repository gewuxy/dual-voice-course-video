# HTML 课件统一模板 · 儿童蜡笔手绘风

适用：K-2 / K3-5 全部 HTML 课件（放映版 1920×1080）
风格来源：班长竞选 PPT（16:9、彩色蜡笔、手绘贴纸、儿童画风，句子短、字号大、活泼统一）
本文件里的所有数值都来自对该 PPT 的**实测反推**（OCR 取字框 + 主色统计），不是拍脑袋。

---

## 一、实测得到的版式规律（最重要）

原 PPT 为 2848×1600，下列百分比均已换算成「占画面高度/宽度」，可直接套到 1920×1080。

| 元素 | 实测占画面高 | 换算 1080 高 | 模板取值 |
|---|---|---|---|
| 封面主标题（3 字「班长！」） | 30.4% | 328px | 230px（6~8 字档） |
| 封面次标题（3 字「我想当」） | 23.8% | 257px | 150px |
| 封面署名 / 班级 | 5.2% | 56px | 46px |
| 内页大标题 | 10.9% ~ 15.3% | 118~165px | **130px** |
| 内页正文 | 4.9% ~ 8.1% | 53~87px | **62px** |
| 卡片小标题 | 5.9% ~ 6.1% | 64~66px | 68px |
| 页脚 / 说明 | 4.9% | 53px | 34px |

关键结论：**标题要占画面高度的 1/8 ~ 1/3，字数越少字越大。**
（对比：之前 L12 封面主标题只占 5.4%，所以显得小气、没有封面感。）

版位规律（从上往下）：

| 区域 | 占画面高度位置 | 说明 |
|---|---|---|
| 页标题 | 距顶 7% ~ 20% | 顶部留白，标题独占一条 |
| 主体内容 | 距顶 25% ~ 75% | 卡片 / 列表 / 图文居中 |
| 收尾句或标签组 | 距顶 84% ~ 93% | 底部一条金句或 3 个小标签 |
| 页脚 | 距顶 ~95% | 页码 + 品牌 |

三列卡片横向位置：x ≈ 10% / 40% / 72%（不是等分，中间略偏，手绘感）。
列表页左对齐起点：x ≈ 16%~18%，右侧留给插画。

## 三、模板内置的 8 类页面

| # | class | 用途 | 关键组件 |
|---|---|---|---|
| 1 | `.cover` | 封面 | 标签贴纸 + 次标题 + 主标题（蜡笔高亮）+ 导语 + 四色蜡笔条 |
| 2 | `.goals` | 本课目标 | 两张倾斜贴纸卡 + 胶带 |
| 3 | `.explain` | 讲解（左文右图） | 手绘编号圆点 + 相框贴纸（可放图/emoji） |
| 4 | `.cards` | 三列卡片 | 3 张贴纸卡，各自微旋转不同角度 |
| 5 | `.list` | 条目列表 | 5 条手绘描边条，奇偶反向微旋 |
| 6 | `.quiz` | 课堂互动 | 提问气泡 + A/B/C 选项（`.right` 标正确答案） |
| 7 | `.summary` | 总结 | 中央大卡片 + 三句话 |
| 8 | `.ending` | 封底 | 超大「下次见！」+ 品牌标语 |

装饰件复用清单：`.blob`（蜡笔色块，不规则圆角）、`.sticker`（贴纸卡）、`.tape`（胶带）、`.mark`（文字背后蜡笔高亮）、`.ul`（手绘波浪下划线）、`.num`（手绘圆圈序号）。

## 四、怎么用

1. 复制 `template.html` → 重命名为课程页（如 `L13_xxx.html`）。
2. 只改 `<section class="slide">` 里的文字和 emoji，**不要动 `<style>`**（改风格只改 `:root` 变量）。
3. 加页：复制任一 `<section class="slide">` 块，改 class 与内容；脚本自动识别页码圆点。
4. 放映：`←` `→` 或空格翻页；底部圆点可跳转；窗口自适应缩放。
5. 导出：浏览器全屏截图，或用 puppeteer 按页截图（`--force-device-scale-factor=2` 得 3840×2160）。

### 字号速查（改标题时对照）

| 场景 | 推荐 font-size | 最多字数（单行） |
|---|---|---|
| 封面主标题 | 230px | 7~8 字 |
| 封面次标题 | 150px | 8~10 字 |
| 内页大标题 | 130px | 12~13 字 |
| 卡片标题 | 68px | 8~10 字 |
| 正文 | 62px | 每行 ≤ 22 字 |
| 小字说明 | 46px | — |

超过字数就**换行或缩短文案**，不要缩小字号——儿童课件宁可字大、字少。

## 五、附：视频号封面（同一风格）要点

- 尺寸 1080×1920（9:16），JPG ≤ 5MB；**安全核心区是中央 1080×1080**（朋友圈分享按 1:1 居中裁切）。
- 主标题占画面高 1/4 ~ 1/3（实测爆款封面主标题字高 ≈ 30%）。
- 主体占画面 50%~60%，背景简化；带人脸/角色表情点击率更高。
- 深底浅字或浅底深字的高对比，避免米底配灰字这类低对比。
- 微信对「纯色背景 + 小字」压缩极狠，务必加渐变/色块/插画质感。
